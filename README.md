# Odu Yoruba · Consultas de Diloggún e Ifá

App web (PWA) para olorishas y babalawos: registra a tus consultados, sus consultas de Diloggún (256 oddun) e Ifá (256 Odu),
el ebbó marcado y cuándo volver. Incluye la biblioteca de signos con refranes, Orishas, iré/osogbo, consejos, prohibiciones, ebbó y patakí.

- Sin configurar: MODO DEMO (los datos quedan en el dispositivo).
- Con Supabase: cuentas y datos en la nube; cada usuario ve solo lo suyo (Row Level Security).

## Puesta en marcha
1. En Supabase > SQL Editor, ejecutar `supabase/schema.sql`.
2. En Supabase > Authentication > URL Configuration, poner como Site URL la dirección publicada.
3. Pegar Project URL y anon key en `config.js`.

Contenido de estudio. El ebbó y las prohibiciones los marca siempre un olorisha o babalawo consagrado.
