# Odu Yoruba · Diloggún e Ifá

App web (PWA) con los signos del Diloggún (16 oddun y 256 compuestos) y de Ifá (16 Meji y 240 Omoluos):
refranes, Orishas que hablan, iré y osogbo, consejos, prohibiciones, ebbó y patakí.

Para instalarla: abre el sitio en el teléfono y elige "Agregar a pantalla de inicio".

Contenido de estudio. El ebbó y las prohibiciones los marca siempre un olorisha o babalawo consagrado.
